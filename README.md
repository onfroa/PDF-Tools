# PDF Tools

A collection of PDF utilities that runs directly in your web browser, with no files leaving your device.

**Live website:** [pdf-tools-auy.pages.dev](https://pdf-tools-auy.pages.dev/)

## Tools and Functions

### 1. Images to PDF

Convert JPG, PNG, and WEBP images into PDF documents.

- Upload multiple images at once.
- Preview images and remove unwanted files.
- Drag and drop images to rearrange their page order.
- Move images up or down on mobile devices.
- Choose portrait or landscape orientation.
- Select Fit to Image, A4, Letter/Short, Legal, or A3 page size.
- Choose how images fit on each page.
- Select no margin, small margin, or large margin.
- Choose the output image quality.
- Merge all images into one PDF or create a separate PDF for every image.

### 2. PDF to JPG

Turn every page of a PDF into a JPG image.

- Upload a PDF and preview its pages.
- Choose standard, high, or maximum image quality.
- Download individual page images.
- Download all converted pages together as a ZIP file.

### 3. Edit PDF

Make page-level changes to a PDF before saving a new copy.

- Preview every page in the document.
- Rearrange pages using drag and drop or mobile ordering controls.
- Rotate individual pages or rotate all pages left, right, or upside down.
- Delete unwanted pages.
- Insert blank pages.
- Add pages from another PDF.
- Save the edited document as a new PDF file.

> This tool edits PDF pages and their order. It does not rewrite existing text, images, links, or other content inside a page.

### 4. Merge PDF

Combine multiple PDF documents into one file.

- Upload several PDF files.
- Preview the uploaded documents.
- Rearrange files using drag and drop or mobile ordering controls.
- Remove unwanted files before merging.
- Download the combined PDF.

### 5. Split PDF

Extract selected pages from a PDF.

- Preview every page in the uploaded PDF.
- Select the pages you want to extract.
- Create one PDF containing all selected pages.
- Save selected pages as separate PDF files in a ZIP archive.

### 6. Compress PDF

Reduce the file size of scanned or image-heavy PDFs.

- Upload and preview the PDF you want to compress.
- Choose the compression level and output quality.
- Compare the original and estimated output sizes.
- Download the compressed PDF directly to your device.

> Text-based or already optimized PDFs may not become much smaller. Compression can also reduce image quality.

### 7. PDF Information

Inspect a PDF without changing it.

- View the file name, file size, page count, first-page dimensions, and number of different page sizes.
- View available PDF metadata, including the PDF version, title, author, creator, producer, creation date, and modification date.
- Detect common page sizes such as A4, Short bond paper/Letter, Long bond paper, Legal, and A3.
- See the recommended paper, orientation, scale, and printer setting.
- Receive guidance for mixed or custom page sizes.

## Offline Use

The website works offline after it has been opened successfully at least once while connected to the internet. The browser saves the core website files so the tools can be reopened and used without a connection.

To prepare it for offline use:

1. Open the live website while connected to the internet.
2. Wait for the page to finish loading.
3. Reopen the same website later using the same browser and device.

Offline access may stop working if the browser cache or website data is cleared. A first-time visit still requires an internet connection, and private browsing modes may remove offline data when the private session closes.

## Main Features

- Private, browser-based file processing.
- Files are processed locally and are not uploaded to a conversion server.
- Works offline after the first successful online visit.
- No account, database, cloud storage, or conversion history.
- Drag-and-drop and mobile-friendly ordering controls.
- Responsive desktop and mobile layouts.
- Automatic downloads after processing.
- Installable web-app support on compatible browsers and devices.

## Privacy

Selected files stay on the user's device and are processed inside the current browser session. The website does not store documents, images, or conversion history. Refreshing or closing the page clears the files selected in the app, although completed downloads remain on the device.

## Browser and File Notes

- Use an up-to-date version of Chrome, Edge, Firefox, or Safari.
- Large PDFs or high-resolution images may take longer and use more device memory.
- Damaged, unsupported, or password-protected PDFs may not open correctly.
- Keep the page open until processing and downloading are complete.
- Always check an edited or converted document before printing or sharing it.
